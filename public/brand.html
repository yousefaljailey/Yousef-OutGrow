How a chosen direction rolls out

The site's fonts are tokenized — --font-display and --font-body in one CSS file — so the type system applies in a single line. The mark replaces the favicon, the og-card, and the header wordmark the same day. Print and signage follow at leisure. Nothing here requires a rebuild; that was the point of the token work.
